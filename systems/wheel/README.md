# Interactive Radial Wheel

**Platform: iOS (Safari / Home Screen app), web app, website. NOT for Roblox Studio, PC or Xbox engines.**

## What it is (plain English)
WheelMenu.js: a touch/mouse wheel for tools, weapons, equipment, armor and SPRAID commands, with sub-wheels.

## Details
Items look like {label, icon, active?, action?, children?, keepOpen?}.

## How to use it
`new WheelMenu(divElement); wheel.toggle(items).`

It is plain JavaScript (ES modules) with three.js, so it can be copied into any other ARERPS web place (for example a coastal map). Needs no build step.
