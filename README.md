# arerps-website
A.R.E.R.P.S. - Advanced Roleplay Emergency Response Protection System Official Website

## 🎮 Play the 3D world
Open `play.html` (live at `https://goinssouthernlegacy.github.io/arerps-website/play.html` once GitHub Pages is on).
Features: Appalachian Aquatic Discovery Center campus, river, forest, wind-swayed grass/trees, day/night, full weather (rain, storms, supercell, snow, fog), lightning (rarely hits players, can ignite buildings), fire & hose firefighting, first-person with SCBA mask + breathing audio, radial wheel (tools, weapons, armor, SPRAID), PIN-protected admin panel (disasters are off until an admin arms them).

Controls: WASD / joystick to move, drag to look, pinch or FPS button for first person, Q or Wheel button for the wheel, Space or USE for the tool.
Graphics: `?q=high` (bloom, more trees) or `?q=low` (phones). Reusable systems live in [`systems/`](systems/README.md) (iOS / web only — not Roblox/PC/Xbox).
Honest note: visuals are procedural (generated by code). For photoreal buildings/vehicles, add real `.glb` models and textures.
